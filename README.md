# price-compare

A small Python tool that compares listing prices between a public storefront and
public reference-price sources, and reports the items with the largest price gap.
Both loose cards and graded ("slab") listings are covered, each against its own
reference. For full design notes, configuration, and the data-delivery convention,
see [`CLAUDE.md`](CLAUDE.md).

## Setup

```bash
pip install -r requirements.txt
playwright install chromium   # the live listing fetch drives a real browser (headful)
cp .env.example .env          # all variables optional; defaults shown in the file
```

## Usage

```bash
python -m comc_scanner list-groups            # the 4 canonical scan groups (no network)
python -m comc_scanner scan --group 1         # one group: loose NM + slabs, 20% min discount
python -m comc_scanner scan --group all       # all four groups in sequence
python -m comc_scanner scan --group all --min-price 5 --min-discount 10   # diagnostic run (floor $5, 10%)
python comc_summary.py results/comc_deals_grupo1_latest.json -o results/comc-grupo1-<date>.md --group 1 --sensitivity 10,15,20
python -m comc_scanner scan --sets "Base Set" --era vintage --raw-only --min-discount 25
```

Every run starts from scratch and uses only today's data (no resume cursor; the
reference snapshot is re-downloaded; the per-card cache is dated). Run
`python -m comc_scanner --help` for the full flag list.

### Delivery

Results land in `results/comc_deals_<scope>_latest.json`. The canonical delivery
(markdown pasted in the chat) is generated by the repo tool — never hand-built:

```bash
python comc_summary.py results/comc_deals_grupo1_latest.json -o results/comc-grupo1-<date>.md --group 1
```
